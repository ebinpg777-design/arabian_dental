Dynamic Excel Report Builder for Odoo

by Ebin P G

Build and export custom Excel & CSV reports for any Odoo model — no developer needed. Pick fields (including related Many2one, Many2many and One2many sub-fields), filter, group and aggregate, add formula columns, apply conditional formatting and charts, style the sheet, and preview live before you download. Save every configuration as a reusable template — or schedule it by email. A powerful self-service reporting tool for business users.

# No code to write — you configure everything visually.
# The only things you ever type are optional, and look like this:

# 1) A domain to filter the records (visual builder or raw):
[('state', '=', 'sale'), ('amount_total', '>', 1000)]

# 2) A formula column, referencing other fields with {curly braces}:
{price_unit} * {product_uom_qty} * (1 - {discount} / 100)

# Everything else — fields, grouping, aggregation, conditional
# formatting, charts, styling — is point & click.

✎ SETUP

User Guide

Excel Report Builder — Installation & Usage

Install the module — it depends only on base and web, so it works with any Odoo 19 edition. Open any list view, then launch the Export Builder from the control panel. Pick the columns you want — search, quick-add, drill into related Many2one / Many2many / One2many sub-fields, then reorder them and rename headers as needed.

Refine the report: set a domain to filter records, switch on Group mode to group by a field (with day / week / month periods) and aggregate measures, add formula columns and analytic transforms, apply per-column conditional formatting and number formats, and optionally add a chart. Style it with header colours, a frozen header, zebra rows, a totals row and AutoFilter — the live preview updates as you go.

When it looks right, download the .xlsx or .csv, or click Save to store the configuration as a reusable template — saved templates appear as one-click Quick Export options. To automate it, enable Scheduled Email Delivery with a daily / weekly / monthly frequency and a list of recipients.
