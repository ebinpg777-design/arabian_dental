HOW IT WORKS

The button makes the reset link Odoo's "Send Password Reset" would email and opens WhatsApp - on a phone, WhatsApp itself; on a computer, WhatsApp Web or the desktop app - with the message written. Without a number on the user, WhatsApp asks whom to send it to. Administrators only, never for yourself or an archived user. Depends only on Odoo's signup module.
