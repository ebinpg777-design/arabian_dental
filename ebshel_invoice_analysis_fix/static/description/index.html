Invoices Analysis: Amounts in the Pivot

In Odoo 20 the Invoices Analysis pivot shows its months and categories but not a single amount. Install this and Untaxed Amount, Total, Margin and Inventory Value are back.

What was wrong

Odoo 20 declares the report's amounts as "sum in company currency". The web client asks for that figure next to every amount, as a fallback for groups that mix currencies, and throws it away in any group with a single currency. For these four fields that is their own figure, so every cell of the pivot and every group total of a grouped list stays blank. The graph is not affected.

What this module does

It declares the four amounts as plain sums, the way every other amount in Odoo is declared. The client then shows the sum in a group with one currency and the converted sum in a group that mixes currencies. No configuration, no data changed; it installs itself with Accounting.
