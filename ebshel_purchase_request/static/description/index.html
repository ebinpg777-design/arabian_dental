✎ SETUP

User Guide

Purchase Request Management — Installation & Usage

Install the module — it depends on purchase, stock, analytic, account and mail, so it plugs straight into your existing Purchase and Inventory setup. Open Purchase Requests from the menu and configure your approval levels under Configuration before raising the first request.

Create a request, add product lines and submit it — it routes automatically to the matching approval level based on amount, department or category. Once approved, create an RFQ for one or several requests at once, capture vendor quotations, and use Compare & Select Winner to review them side-by-side. Award a single vendor or split the lines across several, then click Create Purchase Order.

Track everything from the Procurement menu — dashboards for overall spend and a per-department insight cockpit are available out of the box. Role assignment (User, Approver, Manager, Procurement Officer, Administrator) is managed from Settings → Users, and approval/award policies from the module's own Configuration menu.
