Advanced Stock Reports

Nineteen inventory and manufacturing reports, every figure reconciled to the Odoo valuation.

One engine, not nineteen queries

A daily movement table and a daily valuation table mirror, line for line, how Odoo 19 values stock: standard price history, AVCO replay, FIFO stack, anchored on the current quants, per company and reporting timezone. Every report reads those tables, so the ledger, the aging, the turnover and the GST register all foot to Inventory > Reporting > Stock.

Kept current automatically

Every write path that changes a done move's value feeds a recompute queue: adjust valuation, vendor bills, landed costs, purchase price edits, backdated pickings, move line corrections, standard price changes. A five-minute cron rebuilds only what changed; a health check compares the tables with Odoo's live figures.

The reports

Stock

  • Stock ledger and stock card, with a valuation adjustment column that makes every warehouse foot to the company value
  • Inventory aging (valuation stack or physical in-date)
  • Slow and non-moving stock
  • ABC / XYZ classification
  • Turnover and days of cover
  • Valued count variance
  • Scrap and returns by reason
  • Inward, outward, internal and dropship registers

Manufacturing

  • Planned vs actual consumption, with the BoM quantity frozen at confirmation
  • Work in progress at a date, month-end snapshots
  • MO cost and production analysis, BoM cost vs real cost
  • MO component shortage

Purchase and sales

  • Customer OTIF
  • Vendor OTIF beside Odoo's vendor delay rate
  • Purchase price variance
  • Open order shortage

Accounting and India GST

  • Inventory vs general ledger
  • Bill to receive, billed not received, invoices to be issued, invoiced not delivered
  • GST stock register (Rule 56 grouping, loss categories by reason)
  • Monthly production account

Output

  • On screen with list, pivot and graph views
  • Excel (constant memory, no row limit)
  • PDF, landscape, with a configurable row cap

Security

Three groups: User, See Values and Manager. Without See Values, cost and value columns disappear from the screen, from Excel and from PDF. Multi-company record rules on every stored table.

Compatibility

Odoo 19.0 Community, designed to install on Enterprise. Depends on stock_account, mrp_account, purchase_stock and sale_stock. Uses xlsxwriter, which ships with Odoo. No JavaScript, no external library.
